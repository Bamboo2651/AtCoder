# 順列と逆順列を扱うクエリ

## 問題の概要

`1` から `N` までの整数を並べた順列

\[
P=(P_1,P_2,\ldots,P_N)
\]

が与えられます。

この順列に対して、`Q` 個のクエリを順番に処理します。

クエリには、次の2種類があります。

### クエリ1

```text
1 x y
```

`P_x` と `P_y` を入れ替えます。

### クエリ2

```text
2
```

現在の順列 `P` を、その逆順列 `P'` に置き換えます。

逆順列 `P'` は、すべての `i` について次を満たす順列です。

\[
P'_{P_i}=i
\]

すべてのクエリを処理したあとの順列を出力します。

---

## 逆順列とは

逆順列は「それぞれの数字が何番目にあるか」を並べたものです。

例えば、次の順列を考えます。

```text
P = [2, 5, 3, 1, 4]
```

それぞれの数字がある位置を調べます。

| 数字 | 位置 |
|---:|---:|
| 1 | 4 |
| 2 | 1 |
| 3 | 3 |
| 4 | 5 |
| 5 | 2 |

したがって、逆順列は次のようになります。

```text
inverse = [4, 1, 3, 5, 2]
```

これは次の関係を表しています。

```text
inverse[1] = 4
inverse[2] = 1
inverse[3] = 3
inverse[4] = 5
inverse[5] = 2
```

つまり、

```text
inverse[数字] = その数字がPの何番目にあるか
```

という意味です。

---

## 単純な方法の問題点

クエリ2が来るたびに、現在の順列から逆順列を作り直すことを考えます。

逆順列を作るには、`N` 個の要素をすべて確認する必要があります。

そのため、クエリ2を1回処理する計算量は `O(N)` です。

クエリが最大 `Q` 回あるので、最悪の場合は、

\[
O(NQ)
\]

となります。

今回の制約は、

```text
N ≤ 5 × 10^5
Q ≤ 5 × 10^5
```

です。

`NQ` は最大で、

\[
2.5 \times 10^{11}
\]

程度になるため、制限時間内には処理できません。

---

## 考え方

現在の順列 `P` だけではなく、その逆順列 `inverse` も同時に管理します。

```text
P[i]       = i番目にある数字
inverse[x] = 数字xがある位置
```

例えば、

```text
P = [2, 5, 3, 1, 4]
```

なら、

```text
inverse = [4, 1, 3, 5, 2]
```

です。

この2つを管理すると、それぞれのクエリを `O(1)` で処理できます。

---

## クエリ1の処理

クエリ1では、位置 `x` と位置 `y` の値を入れ替えます。

```text
1 x y
```

入れ替える前の値を、次のようにします。

```python
value_x = P[x]
value_y = P[y]
```

その後、`P[x]` と `P[y]` を入れ替えます。

```python
P[x], P[y] = P[y], P[x]
```

ただし、`P` を変更したので、逆順列 `inverse` も更新する必要があります。

入れ替える前は、

```text
value_xは位置xにある
value_yは位置yにある
```

という状態でした。

入れ替えたあとは、

```text
value_xは位置yにある
value_yは位置xにある
```

となります。

したがって、逆順列を次のように更新します。

```python
inverse[value_x] = y
inverse[value_y] = x
```

ほかの数字の位置は変わっていないので、更新する必要はありません。

この処理の計算量は `O(1)` です。

---

## クエリ2の処理

クエリ2では、現在の順列を逆順列に置き換えます。

すでに `inverse` に逆順列を保存しているため、作り直す必要はありません。

```python
P, inverse = inverse, P
```

この1行で、2つのリストを入れ替えられます。

ここで重要なのは、

> 逆順列の逆順列は、元の順列になる

という性質です。

数式では次のように表せます。

\[
(P^{-1})^{-1}=P
\]

そのため、入れ替えたあとも、

```text
P       = 現在の順列
inverse = 現在の順列の逆順列
```

という関係が保たれます。

リストの中身をコピーするのではなく、変数が参照するリストを入れ替えているだけなので、この処理も `O(1)` です。

---

## 1-indexedで管理する理由

問題文では、順列の位置が `1` から `N` までで表されています。

Pythonのリストは通常 `0` から始まりますが、今回は先頭に使わない `0` を追加します。

```python
P = [0] + list(map(int, input().split()))
```

例えば、入力が次の場合、

```text
2 5 3 1 4
```

リストの中身は次のようになります。

```text
P = [0, 2, 5, 3, 1, 4]
```

これによって、問題文の `P_1` をそのまま `P[1]` として扱えます。

```text
P[1] = 2
P[2] = 5
P[3] = 3
P[4] = 1
P[5] = 4
```

添字から `1` を引く必要がないため、実装が分かりやすくなります。

---

## 逆順列の作り方

最初に与えられた順列から、逆順列を作ります。

```python
inverse = [0] * (N + 1)

for i in range(1, N + 1):
    inverse[P[i]] = i
```

`P[i]` は、位置 `i` にある数字です。

したがって、

```python
inverse[P[i]] = i
```

とすることで、その数字が位置 `i` にあることを記録できます。

例えば、

```text
P[1] = 2
```

なら、数字 `2` は位置 `1` にあります。

```python
inverse[2] = 1
```

となります。

---

## 完成コード

```python
N, Q = map(int, input().split())

P = [0] + list(map(int, input().split()))
inverse = [0] * (N + 1)

for i in range(1, N + 1):
    inverse[P[i]] = i

for _ in range(Q):
    query = list(map(int, input().split()))

    if query[0] == 1:
        x = query[1]
        y = query[2]

        value_x = P[x]
        value_y = P[y]

        P[x], P[y] = P[y], P[x]

        inverse[value_x] = y
        inverse[value_y] = x

    else:
        P, inverse = inverse, P

print(*P[1:])
```

---

## コード全体の解説

### 入力を受け取る

```python
N, Q = map(int, input().split())
```

- `N`：順列の要素数
- `Q`：クエリ数

---

### 順列を1-indexedで保存する

```python
P = [0] + list(map(int, input().split()))
```

先頭に使わない `0` を追加して、問題文と同じ添字で扱えるようにしています。

---

### 逆順列を用意する

```python
inverse = [0] * (N + 1)
```

逆順列を保存するためのリストです。

---

### 最初の逆順列を作る

```python
for i in range(1, N + 1):
    inverse[P[i]] = i
```

数字 `P[i]` が位置 `i` にあることを記録します。

---

### クエリを受け取る

```python
for _ in range(Q):
    query = list(map(int, input().split()))
```

`Q` 個のクエリを順番に処理します。

---

### クエリ1を判定する

```python
if query[0] == 1:
```

クエリの最初の数字が `1` なら、入れ替えクエリです。

---

### 入れ替え前の値を保存する

```python
value_x = P[x]
value_y = P[y]
```

逆順列を更新するために、入れ替える前の値を保存します。

ここで値を保存せずに先に入れ替えてしまうと、どの数字がどこへ移動したのか分かりにくくなるので注意が必要です。

---

### 順列を入れ替える

```python
P[x], P[y] = P[y], P[x]
```

Pythonでは、この書き方で2つの値を簡単に入れ替えられます。

---

### 逆順列を更新する

```python
inverse[value_x] = y
inverse[value_y] = x
```

位置 `x` にあった `value_x` は位置 `y` へ移動します。

位置 `y` にあった `value_y` は位置 `x` へ移動します。

---

### クエリ2を処理する

```python
else:
    P, inverse = inverse, P
```

現在の順列と逆順列を入れ替えます。

リスト全体を作り直さないため、`O(1)` で処理できます。

---

### 最終結果を出力する

```python
print(*P[1:])
```

`P[0]` は添字を合わせるための使わない要素なので、`P[1:]` だけを出力します。

先頭の `*` を使うと、リストの要素を空白区切りで出力できます。

---

## 難しいポイント

### 1. クエリ2は逆順列を作る操作

条件

\[
P'_{P_i}=i
\]

は、少し分かりにくい表現です。

これは、

```text
Pの位置iに数字xがあるなら、
逆順列の位置xにはiが入る
```

という意味です。

つまり、

```python
inverse[P[i]] = i
```

と表せます。

---

### 2. 順列と逆順列を両方更新する

クエリ1で `P` の値だけを入れ替えると、`inverse` が古い状態のままになってしまいます。

その状態でクエリ2を行うと、間違った結果になります。

そのため、`P` を変更したときは、必ず `inverse` も更新します。

```python
P[x], P[y] = P[y], P[x]

inverse[value_x] = y
inverse[value_y] = x
```

---

### 3. クエリ2で本当に入れ替えるだけでよい理由

現在、

```text
inverse = Pの逆順列
```

という関係になっています。

クエリ2のあとでは、古い `inverse` が新しい `P` になります。

そして、古い `P` は新しい `P` の逆順列です。

これは、逆順列を2回取ると元に戻るためです。

```text
P → inverse → P
```

したがって、次の入れ替えだけで関係を維持できます。

```python
P, inverse = inverse, P
```

---

### 4. リストをコピーしているわけではない

次の処理は、リストの全要素をコピーしているわけではありません。

```python
P, inverse = inverse, P
```

2つの変数が参照するリストを交換しています。

そのため、リストの長さが `N` でも計算量は `O(1)` です。

---

## サンプルの流れ

最初の順列を次のようにします。

```text
P = [2, 1, 3, 5, 4]
```

クエリが、

```text
1 2 4
```

なら、2番目と4番目を入れ替えます。

```text
P = [2, 5, 3, 1, 4]
```

次にクエリ2を処理します。

数字の位置を調べると、

| 数字 | 位置 |
|---:|---:|
| 1 | 4 |
| 2 | 1 |
| 3 | 3 |
| 4 | 5 |
| 5 | 2 |

なので、逆順列は、

```text
P = [4, 1, 3, 5, 2]
```

となります。

---

## 計算量

最初の逆順列作成には、`N` 個の要素を確認します。

\[
O(N)
\]

各クエリは、どちらも定数回のリスト操作だけです。

\[
O(1)
\]

`Q` 個のクエリ全体では、

\[
O(Q)
\]

最後の出力には、

\[
O(N)
\]

かかります。

したがって、全体の計算量は、

\[
O(N+Q)
\]

です。

使用するリストは、順列と逆順列の2つなので、空間計算量は、

\[
O(N)
\]

です。

---

## まとめ

この問題で重要なポイントは、次の3つです。

1. クエリ2は、現在の順列を逆順列にする操作
2. 現在の順列と逆順列を両方管理する
3. クエリ2では2つのリストを入れ替えるだけでよい

特に重要な処理は次の部分です。

```python
P, inverse = inverse, P
```

逆順列を毎回作り直さず、あらかじめ両方を管理することで、すべてのクエリを高速に処理できます。
