## 入力
```
n,m = map(int,input().split()) 
```
	空白区切りで入力。
```
box = dict()
```
	辞書型boxを用意する。

```
for _ in range(m):
    am, bm = map(int,input().split())
    if am in box:
        box[am].append(bm)
    else:
        syoki = [bm]
        box[am] = syoki
```
	M回の入力を 辞書型boxにkey(キー)が入っていたら、
	そのままvalue(値)を格納する。
	keyが入っていなかったらキーをbox[am] = syokiでキーと値を登録する。
	入力例
		3 3
		1 2
		2 2
		2 3
		print(box)
		{{1:2},{2:2,3}}

koukan.add(1)

	1をすでに持っているからkoukanに1を入れる。
	set()は重複をなくす

current = deque([1])

```
a = current.popleft()

```
if a in box:
```

```
for i in box[a]:
```

```
if i not in koukan:

	current.append(i)

	キーから取り出したvalueがすでにkoukanに入ってなかったら、
